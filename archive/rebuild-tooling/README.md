# Инструменты разовой перестройки

Исторические скрипты переноса и подготовки первой редакции пяти модулей. Сохранены для разбора происхождения материалов; обычная сборка использует только `tools/build_course.cjs`.

- `snapshot_course.py` — сохранение исходного среза.
- `course_blueprint.py`, `migration_content.py`, `migration_topics.py`, `migrate_course.py` — структура и первоначальная миграция.
- `course_diagrams.py` — исходное построение схем.
- `restore_project_protocols.py` — восстановление протоколов проектов BERT.

Пути к корню проекта учитывают архивное размещение. Миграция завершена и заблокирована; повторная миграция не заменяет редактирование текущих Markdown и `course.json`.
