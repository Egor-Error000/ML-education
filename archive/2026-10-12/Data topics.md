# План: Данные в ML/DL (общее, CV, NLP)

Проходим пункт за пунктом, в порядке ниже. Возможны отступления по ходу вопросов.

## Блок A — Общее (ML/DL data engineering)

1. **Train/val/test split** — виды утечек: group leakage, temporal leakage,
   preprocessing leakage (fit до split). Stratified split.
2. **Дисбаланс классов** — weighted loss, oversampling/undersampling, SMOTE и его
   ограничения, focal loss.
3. **Аугментации: регуляризация vs расширение данных** — где проходит граница,
   когда аугментация ломает семантику (кейс SimCLR/ColorJitter уже затронут).
4. **Шумная и грязная разметка** — confident learning, cleanlab, как находить и
   что делать с mislabeled примерами.
5. **Синтетические данные и data distillation** — когда помогает, когда создаёт
   скрытый bias / distribution shift.
6. **Efficient data loading** — DataLoader, num_workers, prefetch, pin_memory,
   почему CPU-bottleneck (уже встретили на Colab) — системная проблема, не мелочь.
7. **Версионирование датасетов (DVC)** — опционально, если интересен MLOps-уклон.

## Блок B — CV-специфика

1. **Форматы аннотаций** — COCO, VOC, YOLO-формат, конвертация между ними.
2. **Аугментации для detection/segmentation** — синхронная трансформация
   картинки + bbox/маски, почему Albumentations делает это правильно.
3. **Small object detection проблема** — несбалансированность по размеру объектов.
4. **Стриминг больших датасетов** — WebDataset, tar-шардирование (актуально при
   переходе с STL-10/CIFAR на датасеты большего размера).

## Блок C — NLP-специфика

1. **Токенизация** — BPE/WordPiece/SentencePiece: почему так устроены, где
   ломаются (OOV, языки без пробелов, эмодзи/юникод).
2. **Чанкинг длинных текстов** — для эмбеддингов/RAG, overlap, разбиение по
   семантическим границам.
3. **Дедупликация корпусов** — MinHash/LSH, почему критично и для LLM-претрейна,
   и для утечки train/test на маленьких датасетах.
4. **Data-центричный подход к instruction-tuning** — качество > количество.
