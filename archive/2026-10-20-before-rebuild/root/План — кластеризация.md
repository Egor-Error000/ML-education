# План модуля: кластеризация

**Срез источников: 20 октября 2026.** Сохраняются девять учебных глав исходного [плана](<04-clustering/План — кластеризация.md>) и его примеры. Карта source questions, вычислений и ограничений: [редакционная карта курса](<Редакционная карта курса.md>).

## Маршрут и границы

**Общее ядро:** C1 → C2 → C3/C4 → C8 как измерение и представление; затем C9 по задаче. C5 — основа deep-clustering ветки; C6/C7 — CV и NLP ветки. C1 даёт локальное определение эмбеддинга и расстояний: изучение Transformer не требуется. Перед кластеризацией проверить train/test protocol для downstream evaluation и масштабирование из модуля данных.

Результат не называется истинными классами без внешней проверки. Визуализация 2D не доказывает качество кластеров в исходном пространстве. Для каждого алгоритма явно указывать обнаруживаемую структуру, предположения, способ отнести новый объект и поведение шума/пустого кластера.

## Сценарии глав

**Критерий каждой главы:** читатель может выполнить указанный ручной расчёт или выбрать алгоритм для описанной структуры, проверить результат в исходном пространстве и объяснить, какая предпосылка/метрика ограничивает вывод. Проекция сама по себе критерием не считается.

### C1. Постановка, similarity и geometry представлений

**Уровень:** общее ядро. **Предпосылки:** vectors/matrices. **Используют:** все остальные главы и прикладные модели.

**Сценарий:** цель clustering vs labels → unit of observation → Euclidean/Manhattan/cosine/Mahalanobis → scaling/normalization → representation and metric. Локально определить embedding как векторное представление объекта, научаемое или вычисляемое encoder; Transformer не предполагать. Вывести связь cosine и Euclidean для unit vectors. Пример из трёх точек после разного scaling. Схема object → representation → distance → algorithm. Практика: проверить nearest neighbors в original feature space. Ограничения: геометрия — часть модели; metric/scale меняют ответ.

### C2. K-Means, иерархические методы, density и GMM

**Уровень:** общее ядро. **Предпосылки:** C1, expectation/variance. **Используют:** C3–C4/C9.

**Сценарий:** centroid objective and Lloyd steps → K-Means++ → linkage/Ward/dendrogram → DBSCAN/HDBSCAN density/noise → GMM latent assignment and EM. Вывести K-Means assignment/update and one full EM E/M pass for 1D Gaussian mixture. Пример на toy data показывает spherical vs variable-density clusters. Схема алгоритмов разделяет objective, state and output. Практика: run same data with outlier/scale changes. Limits: K-Means convex/spherical assumptions, density varying-scale failure, GMM covariance assumptions.

### C3. Выбор K и устойчивость

**Уровень:** общее ядро. **Предпосылки:** C2 and sampling. **Используют:** any result reporting.

**Сценарий:** inertia elbow → silhouette → gap/reference distribution → bootstrap/subsample stability → model-based criteria/DP mixture overview. Формулы: silhouette and gap with correct within-cluster distance definitions. Example calculates silhouette for one point and shows monotonic inertia even when K is overlarge. Scheme: candidate K × resamples → partitions → stability summary. Practice: choose K using multiple criteria and domain use. Limits: no unique true K in general; stability can reproduce a wrong representation.

### C4. Partition quality and external/internal metrics

**Уровень:** общее ядро. **Предпосылки:** C1–C3. **Используют:** C5–C9.

**Сценарий:** external labels used only as evaluation → purity/permutation issue → ARI/NMI → internal silhouette/DB/coverage → noise/abstention policy. Hand calculate a small contingency table and show purity inflated by singleton clusters. Scheme separates fit data, hidden diagnostic labels, and output report. Practice: report metric alongside cluster size/noise coverage. Limits: labels may encode another task; metric choice changes preference; do not use test labels for hyperparameter tuning without a protocol.

### C5. Deep clustering and frozen embeddings

**Уровень:** основа ветки. **Предпосылки:** C1–C4, neural training basics. **Используют:** C6/C7 and research route.

**Сценарий:** frozen encoder + conventional clustering → DEC Student-t soft assignments/target distribution/KL → iterative refinement → IDEC reconstruction preservation → joint learning alternatives. Derive Student-t assignment and one KL gradient intuition. Example shows collapse or confirmation bias. Scheme distinguishes frozen two-stage pipeline and end-to-end representation/cluster loop. Practice: external validation, nearest-neighbor inspection, augmentation. Limits: pseudo-label feedback can reinforce bad clusters; compare against frozen baseline.

### C6. Image clustering and stream assignment

**Уровень:** основа CV branch. **Предпосылки:** C1–C5 or suitable frozen encoder. **Используют:** downstream CV discovery.

**Сценарий:** pixel/color features → pretrained supervised/self-supervised features → patch/pixel local features → SLIC superpixels → online assignment/outlier/new cluster. Example compares raw pixels and image embeddings on varied background. Diagram input image → global/patch embedding → cluster → region association. Practice: stability across crops and new samples. Limits: semantic clusters need feature/label audit; out-of-sample assignment differs by algorithm.

### C7. Text representations, topics and short texts

**Уровень:** основа NLP branch; Transformer training not required. **Предпосылки:** C1, bag-of-words and linear algebra. **Используют:** discovery/topic work.

**Сценарий:** lexical TF-IDF → LDA topic mixtures → NMF factorization → semantic sentence embeddings and Top2Vec → hybrid short-text. Define document-term matrix and topic mixture. Example compare lexical overlap and semantic-neighbor cases. Scheme contrasts sparse words and dense vectors. Practice: inspect top terms/examples, topic stability and coverage. Limits: coherence metric and language priors do not establish useful topic taxonomy.

### C8. PCA, t-SNE, UMAP and projection distortion

**Уровень:** общее ядро как diagnostic; t-SNE/UMAP theory — углубление. **Предпосылки:** C1, covariance/SVD. **Используют:** C5–C7 and reports.

**Сценарий:** center/scale → PCA/SVD/whitening objective → t-SNE local probability/kl → UMAP graph fuzzy neighbors → projection distortion and parameter sensitivity. Example maps four points and compares original/projection neighbor ranks. Scheme separates fit transform from visualization. Practice: compute silhouette in original space, neighbor preservation and seed variance. Limits: axes/global distances in t-SNE/UMAP are not directly meaningful; fit/test projections require valid transform protocol.

### C9. Clustering inside larger systems

**Уровень:** основа ветки by task. **Предпосылки:** C1–C4 and chosen application. **Используют:** anomaly discovery, pseudo-label, ANN routing.

**Сценарий:** anomaly/regime detection → pseudo-label qualification → IVF coarse partition/ANN routing → streaming updates and drift → complete pipeline/report. Example shows cluster size imbalance and recall cost from wrong routing. Scheme: representation → train centroids/index → assign/query → evaluate downstream task. Practice: compare routing recall/latency and cluster stability. Limits: pseudo-labels are candidates, not ground truth; clustering does not automatically speed a system.
