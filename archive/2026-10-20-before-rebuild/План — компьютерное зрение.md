**Срез источников: 20 октября 2026.** Сохраняется содержание девяти задач текущего [плана CV](<05-computer-vision/План — компьютерное зрение.md>) и добавляется вводная глава, где впервые вводятся общие понятия. Источник нового обсуждения S7 и его точные границы переноса — [реестр интеграции](<05-computer-vision/notes/Интеграция CV-чата S7.md>); полная карта — [редакционная карта курса](<Редакционная карта курса.md>).

## Маршрут и уровни

**Общее ядро:** V0 → V1 классификация → V2 detection → V3 semantic segmentation → V4 instance segmentation. Затем V5 pose, V6 OBB, V7 tracking, V8 depth и V9 open-vocabulary выбираются по задаче. Tracking использует detection/association; OBB использует detection и геометрию угла; open-vocabulary использует alignment текста и изображения. Все главы опираются на данные/аннотации из [модуля данных](<План — данные и признаки.md>), но локально определяют формат входов и выходов.

## V0. Представление изображения и общие блоки модели

**Уровень:** общее ядро. **Предпосылки:** массивы/тензоры, матричное умножение, gradient descent. **Используют:** V1–V9.

**Сценарий:** изображение как H×W×C tensor → color/normalization/resizing → receptive field and feature map → convolution/padding/stride → resolution pyramid → backbone/encoder → neck → task head/decoder. Объяснить вход/выход и форму каждого блока до первой задачи; классифицировать encoder vs decoder by information flow, not naming convention. Пример: одной свёрткой посчитать output shape и receptive field; показать, как stride меняет resolution. Архитектурная схема: image + preprocessing → stages with feature shapes → task-specific head → prediction. Практика: провести shapes на 32×32 image. Ограничения: канал/normalization/layout и coordinates входят в interface; resize/letterbox нужно учитывать при преобразовании predictions.

## Сценарии глав

**Критерий каждой главы:** читатель может пройти путь входа модели до предсказания, воспроизвести указанный расчёт метрики/loss и определить, по каким аннотациям и условиям измеряется результат. Для архитектуры читатель объясняет подписанную схему и знает один task-specific failure mode.

### V1. Image classification, backbone и ViT

**Уровень:** общее ядро. **Предпосылки:** V0, D2/D4/D5. **Используют:** V2–V9 and clustering.

**Сценарий:** image/label unit and split → conv backbone and feature maps → classifier/pooling → ViT patch embedding, attention and positions → training loss and transfer → SSL/MAE/DeiT and resolution. Разобрать cross-entropy, output logits, class imbalance, augmentation and checkpoint choice. Числовой пример patch embedding vs Conv2d and one attention head. Схема показывает CNN stages and token sequence path to logits. Практика: frozen feature linear probe vs fine-tune. Ограничения: ImageNet transfer and linear probing do not establish domain robustness.

### V2. Object detection, matching, AP и NMS

**Уровень:** общее ядро. **Предпосылки:** V0–V1, D7 box coordinates. **Используют:** V4–V7/V9.

**Сценарий:** detection output contract → anchor/grid/query or set prediction → matching/assignment → classification+box losses → IoU variants → decoding/NMS → AP/mAP. Define target boxes and empty/crowd cases. Hand example computes IoU, greedy matching and AP interpolation under explicit protocol. Diagram input→backbone/neck→object queries/heads→boxes/scores→NMS/evaluation. Practice: classify TP/FP by confidence rank and threshold. Limits: AP depends on annotation, IoU threshold, class averaging and benchmark protocol.

### V3. Semantic segmentation, FCN, U-Net и DeepLab

**Уровень:** общее ядро. **Предпосылки:** V0–V1, pixel labels and D7 mask transforms. **Используют:** V4/V8 and spatial outputs.

**Сценарий:** semantic vs instance labels → downsampled feature maps → FCN upsampling/skip → U-Net encoder-decoder → DeepLab context/dilated convolution → pixel loss/ignore masks → IoU/Dice. Пример вычисляет confusion matrix and foreground IoU with absent class policy. Diagram shows multi-scale feature path and per-pixel logits. Practice: inspect boundary and class imbalance errors. Limits: interpolation, void class and image-level split affect score.

### V4. Instance segmentation, RoIAlign и prototype masks

**Уровень:** общее ядро. **Предпосылки:** V2–V3. **Используют:** V7/V9 and object-centric analysis.

**Сценарий:** semantic/instance/panoptic outputs → two-stage detection masks/RoIAlign → one-stage/prototype-mask alternatives → matching/losses → mask AP. Calculate bilinear RoIAlign and combine coefficients with prototype masks. Diagram identifies detection boxes, per-RoI or shared prototype mask head. Practice: evaluate touching instances and occlusion. Limits: ROI coordinate alignment and small-object annotation affect masks.

### V5. Pose and keypoint estimation

**Уровень:** основа pose branch. **Предпосылки:** V0–V2 and coordinate geometry. **Используют:** V7 and action tasks.

**Сценарий:** keypoint annotation/visibility → coordinate regression vs heatmaps → decoding/argmax/subpixel → OKS → top-down vs bottom-up grouping. Hand compute Gaussian heatmap location, OKS weight and one matching. Diagram separates person detector, keypoint head and grouping. Practice: test left/right flips and low-confidence points. Limits: skeleton definition, scale normalization, occlusion and group assignment.

### V6. Oriented boxes and rotated geometry

**Уровень:** основа detection branch. **Предпосылки:** V2 and coordinate transforms. **Используют:** aerial/document/video detection.

**Сценарий:** axis-aligned failure → parameterizations `(cx,cy,w,h,θ)` and polygon → periodic angle / equivalent boxes → rotated IoU/NMS → annotation convention. Example shows angle wrap at π and equivalent representations. Diagram compares rotated polygon and axis-aligned envelope. Practice: round-trip transform and near-square boxes. Limits: periodicity, angle range, non-differentiable polygon overlap and convention-specific labels.

### V7. Multi-object tracking

**Уровень:** основа temporal CV branch. **Предпосылки:** V2, V0, D7 sequence splits. **Используют:** V5/V9 and video systems.

**Сценарий:** per-frame detections → motion state/Kalman prediction → data association/cost → track birth/death/re-ID → MOTA/IDF1/HOTA. Calculate one Kalman step and assignment matrix. Diagram includes frame input, detector, tracker state and identity output. Practice: diagnose ID switch vs false detection. Limits: identity labels, missing detections, camera motion and sequence-level evaluation.

### V8. Depth estimation and scale ambiguity

**Уровень:** основа depth branch. **Предпосылки:** V0–V1, regression and geometry. **Используют:** 3D and robotics branches.

**Сценарий:** metric vs relative depth → monocular scale ambiguity → supervised/self-supervised signals → DPT-style feature processing → losses/metrics (AbsRel, RMSE, δ). Hand example aligns global scale and computes raw vs aligned score. Diagram shows image encoder/multi-scale tokens/depth decoder. Practice: separate invalid pixels and evaluate calibration/scenes. Limits: benchmark scale, camera intrinsics and domain matter.

### V9. Open-vocabulary detection and vision-language alignment

**Уровень:** углубление after V2; basis for multimodal branch. **Предпосылки:** V2, text/image embeddings, D2/D4. **Используют:** promptable annotation and open-world systems.

**Сценарий:** closed class label set → vision/text embedding alignment → grounding/localization → open-vocabulary detector outputs → promptable concept segmentation and image/video tracking → evaluation under seen/novel splits. Calculate contrastive score and box/text match. Diagram separately shows image encoder, text prompt encoder, fusion/grounding, detector and mask/tracker. Practice: compare fixed-category and novel-class performance, phrase sensitivity and false positive open-set cases. Limits: open vocabulary is benchmark- and prompt-dependent; not proof of general object understanding.

| Promptable concept detection/segmentation/tracking | [SAM 3 paper/research release](https://ai.meta.com/research/publications/sam-3-segment-anything-with-concepts/); [SAM 3.1 update, 27 Mar 2026](https://ai.meta.com/blog/segment-anything-model-3/) | V4/V7/V9: keep promptable concept segmentation, conventional closed-set instance masks and tracking metrics distinct. ## Практические артефакты

Core route: image label → detector → semantic/instance segmentation. Each experiment preserves source-level split, annotation contract, baseline, prediction visualization and task-specific metric. Advanced tasks are separate project paths. CV examples and their corrected calculations map source questions to the chapter above in the [editorial map](<Редакционная карта курса.md>).
