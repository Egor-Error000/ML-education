## Как проверить понимание

Возьмите B=2, L=7, D=24, H=4 и V=100. Пройдите путь ids → embeddings → Q/K/V → scores → outputs → LM head. Объясните masks и shift. Затем пересчитайте пример внимания из Г и укажите градиент к value первой позиции от loss второй. Ответы приведены в главах; самостоятельный расчёт нужно сделать до их чтения.

Создание этих материалов не меняет статусы освоения/практики. Для этого нужны ваши самостоятельные ответы или артефакты выполнения.
