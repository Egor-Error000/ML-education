# Оформление версии для чтения

[Читать конспекты](<../Читать конспекты.html>) — локальный HTML-документ с навигацией по 95 главам. Он работает без интернета; Markdown-исходники остаются в тематических папках и доступны из каждой главы.

Формулы предварительно набраны KaTeX 0.19.0 (HTML + MathML); во время чтения библиотека не загружается и не исполняется. Локальные CSS и WOFF2 fonts взяты из официального npm-пакета через jsDelivr. Другие форматы шрифтов исключены из CSS, так как используются WOFF2. [Лицензия MIT](katex/LICENSE), [проект KaTeX](https://katex.org/).

Для переноса HTML-версии сохраните папку `оформление` рядом с файлом `Читать конспекты.html`. Для сохранения ссылок на Markdown, планы и источники переносите весь каталог `ML edu plans`.

Сборка: `tmp/build_study_reader.cjs` в корне workspace. Изменения Markdown появятся в HTML после повторной сборки; HTML является версией для чтения, а Markdown — редактируемыми исходниками. Веб-сервис и аккаунт для чтения не требуются.
