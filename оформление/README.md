# Оформление версии для чтения

[Читать конспекты](<../Читать конспекты.html>) — локальный HTML-читатель пяти модулей. Структура и маршруты берутся из `course.json`; учебный текст — из Markdown. Читатель работает без интернета.

Формулы предварительно набраны KaTeX 0.19.0 (HTML + MathML); во время чтения библиотека не загружается и не исполняется. Локальные CSS и WOFF2 fonts взяты из официального npm-пакета через jsDelivr. Другие форматы шрифтов исключены из CSS, так как используются WOFF2. [Лицензия MIT](katex/LICENSE), [проект KaTeX](https://katex.org/).

Для переноса HTML-версии сохраните папку `оформление` рядом с файлом `Читать конспекты.html`. Для сохранения ссылок на Markdown, планы и источники переносите весь каталог `ML edu plans`.

Сборка: `node tools/build_course.cjs` из корня проекта. Проверка соответствия источникам: `node tools/build_course.cjs --check`. Версии и лицензии локально включённых KaTeX/marked — в [tools/vendor](<../tools/vendor/README.md>). Ручное редактирование HTML не используется.

Оригинальные SVG новой редакции находятся в `course/`; прежние подробные Transformer-схемы — в `transformer/`. При сборке они встраиваются в HTML. Подписи и объяснения связей находятся также в учебном тексте; источник SVG остаётся редактируемым.
