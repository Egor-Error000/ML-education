[Lifecycle и обучение агентов](05-lifecycle/%D0%9F%D0%BB%D0%B0%D0%BD%20%E2%80%94%20%D0%B6%D0%B8%D0%B7%D0%BD%D0%B5%D0%BD%D0%BD%D1%8B%D0%B9%20%D1%86%D0%B8%D0%BA%D0%BB%20LLM%20%D0%B8%20%D0%BE%D0%B1%D1%83%D1%87%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B0%D0%B3%D0%B5%D0%BD%D1%82%D0%BE%D0%B2.md): обучение и оценка траекторий.
