## Autoencoder, VAE и GAN: вероятностные основы генерации

**Статус сценария:** authored — расширение CV; приёмка текста отдельно

**Учебный вопрос:** Чем различаются восстановление входа и обучение распределения новых изображений?

**Уровень:** основа ветки. **Предпосылки:** cv-classification

**Потребители:** cv-ddpm, cv-generation-eval

**Порядок объяснения:**

1. Вероятностный вход в генерацию.
2. Autoencoder и VAE.
3. GAN.
4. Разобранный пример: KL и sampling.
5. Самопроверка с ответами.

**Разобранный пример:** Для одного latent dimension $q=\mathcal N(\mu,\sigma^2)$, $p=\mathcal N(0,1)$:
$KL=\tfrac12(\mu^2+\sigma^2-\log\sigma^2-1)$.
При $\mu=1$, $\sigma=0.5$ получаем $0.5(1+0.25-\ln0.25-1)\approx0.81815$. При $\mu=0,\sigma=1$ KL равна 0. Для noise $\epsilon=-2$ reparameterized sample первого posterior $z=1+0.5(-2)=0$.

Если discriminator даёт generated sample вероятность real 0.1, non-saturating loss generator $-\ln0.1=2.30259$. При 0.8 — 0.22314. Эти значения не являются FID или достоверностью конкретной детали изображения.


**Схемы и разбор:** VAE: Image x → encoder → Mean / variance → z via noise → Decoder → likelihood parameters → Reconstruction + KL loss; GAN: Prior noise z → generator → Generated and real images → Discriminator → real score → Раздельные updates D и G.

## DDPM: прямой процесс, noise prediction и обучение

**Статус сценария:** authored — расширение CV; приёмка текста отдельно

**Учебный вопрос:** Как обучение предсказанию шума превращается в генерацию изображения?

**Уровень:** основа ветки. **Предпосылки:** cv-generative

**Потребители:** cv-sampling

**Порядок объяснения:**

1. Прямой процесс фиксирован.
2. Что учится предсказывать сеть.
3. Обратный sampling.
4. Разобранный пример: corruption и reconstruction.
5. Самопроверка с ответами.

**Разобранный пример:** В scalar-примере $x_0=0.8$, $\bar\alpha_t=0.64$, $\epsilon=-0.5$. Тогда $x_t=0.8\cdot0.8+0.6(-0.5)=0.34$. При точном noise estimate восстановление $(0.34-0.6(-0.5))/0.8=0.8$. При estimate $-0.4$ получаем $(0.34+0.24)/0.8=0.725$, noise MSE 0.01, ошибка clean estimate $-0.075$.

Signal-to-noise ratio здесь $\bar\alpha/(1-\bar\alpha)=0.64/0.36\approx1.77778$. При $\bar\alpha=0.01$ SNR около 0.01010: почти весь observation — noise. Но difficult timestep не означает отсутствие population-level information, которой учится denoiser.


**Схемы и разбор:** Training DDPM: Clean x0 + random t, ε → Fixed corruption → xt → Denoiser(xt,t) → ε estimate → Noise MSE → θ update; Sampling DDPM: Gaussian xT → Denoiser → reverse mean → Variance + fresh noise → Повтор до x0 → image.

## DDIM, расписания шума и classifier-free guidance

**Статус сценария:** authored — расширение CV; приёмка текста отдельно

**Учебный вопрос:** Как менять число шагов и силу условия, не смешивая sampler с обучением?

**Уровень:** основа ветки. **Предпосылки:** cv-ddpm

**Потребители:** cv-latent-diffusion

**Порядок объяснения:**

1. Три независимых решения.
2. DDIM.
3. Classifier-free guidance.
4. Разобранный пример: guidance и один переход.
5. Самопроверка с ответами.

**Разобранный пример:** Пусть scalar predictions $\epsilon_u=0.2$, $\epsilon_c=0.5$. При $s=3$ результат $0.2+3\cdot0.3=1.1$, выходящий за интервал исходных predictions. Guidance является extrapolation, поэтому сильное условие может увести trajectory в плохо обученные области.

Для $x_t=0.34$, $\bar\alpha_t=0.64$, predicted noise $-0.5$ получили $\hat x_0=0.8$. При $\bar\alpha_s=0.81$ deterministic DDIM step даёт $x_s=0.9\cdot0.8+\sqrt{0.19}(-0.5)\approx0.50206$. Финальный clean estimate и очередное noisy state различаются.

Если sampler использует 30 timesteps и каждый требует conditional/unconditional forward, это до 60 branch evaluations. При времени одного sequential branch 20 ms грубая оценка 1.2 seconds без decoder и overhead. Совместный batch меняет реальное время и peak memory, поэтому измерения важнее этого сложения.


**Схемы и разбор:** DDIM step: xt + timestep t → Predict ε → estimate clean x0 → Выбранный следующий noise level s → Согласованный переход → xs; CFG: Noisy latent + condition → Conditional εc; empty εu → εu + scale×(εc−εu) → Guided prediction → sampler.

## Latent diffusion: autoencoder, denoiser и conditioning

**Статус сценария:** authored — расширение CV; приёмка текста отдельно

**Учебный вопрос:** Что меняется, когда diffusion работает в пространстве сжатых признаков?

**Уровень:** основа ветки. **Предпосылки:** cv-sampling, cv-vit

**Потребители:** cv-dit-flow, cv-control, cv-generation-eval

**Порядок объяснения:**

1. Два этапа обучения.
2. Denoiser и cross-attention.
3. Sampling и границы переноса.
4. Разобранный пример: размеры и attention.
5. Диагностика.
6. Самопроверка с ответами.

**Разобранный пример:** Для $512\times512$ RGB image число values $3\cdot512^2=786432$. При $f=8$, $C_z=4$ latent $4\times64\times64$ содержит 16384 values, в 48 раз меньше. Spatial positions меньше в 64 раза, но это не обещает 48-кратного ускорения: channels blocks и conditioning имеют собственную стоимость.

На resolution $32\times32$ имеется 1024 image queries. При 77 text states одна cross-attention matrix содержит $1024\cdot77=78848$ scores на head. Полное spatial self-attention на том же уровне содержит $1024^2=1048576$ scores. При восьми heads эти числа умножаются на 8; optimization kernels могут не материализовать всю matrix одновременно.


**Схемы и разбор:** Autoencoder stage: Image x → Encoder E → latent z → Decoder D → reconstruction → Perceptual / reconstruction loss; Latent diffusion: z + noise + timestep → Text encoder → condition states → U-Net + cross-attention → ε → Sampler → z0 → decoder D.

## DiT и flow matching: Transformer и цели обучения

**Статус сценария:** authored — расширение CV; приёмка текста отдельно

**Учебный вопрос:** Почему Transformer-backbone и flow matching являются разными выборами?

**Уровень:** углубление. **Предпосылки:** cv-latent-diffusion

**Потребители:** Самостоятельное применение.

**Порядок объяснения:**

2. Diffusion Transformer.
3. Conditional flow matching.
4. Разобранный пример: patch count и velocity.
5. Ограничения и сравнение.
6. Самопроверка с ответами.

**Разобранный пример:** Latent $4\times32\times32$, patch size 2 даёт $16^2=256$ tokens, размер flattened patch $4\cdot2^2=16$. При patch size 1 — 1024 tokens; full attention scores вырастают с 65536 до 1048576 на head, в 16 раз. Число latent scalar values не меняется.

Scalar noise $x_0=-1$, data $x_1=3$, timestep $t=0.25$. Path point $x_t=0.75(-1)+0.25\cdot3=0$, velocity target 4. Если prediction 3.5, squared error 0.25. Для constant velocity 4 Euler step $\Delta t=0.1$ переносит point 0 в 0.4. В реальной learned field velocity зависит от state и timestep; это только ручной пример интегрирования.


**Схемы и разбор:** DiT: Noisy latent → patchify → Tokens + position / timestep → Transformer + adaptive norm → Unpatchify → prediction tensor; Flow matching: Noise x0 + data x1 + t → Sample xt along known path → Velocity net → vθ(xt,t) → MSE target; ODE at inference.

## ControlNet, inpainting, image-to-image и LoRA

**Статус сценария:** authored — расширение CV; приёмка текста отдельно

**Учебный вопрос:** Как направлять генерацию геометрией, исходным изображением и небольшими обновлениями весов?

**Уровень:** углубление. **Предпосылки:** cv-latent-diffusion

**Потребители:** Самостоятельное применение.

**Порядок объяснения:**

1. Разные виды управления.
2. ControlNet.
3. Image-to-image и inpainting.
4. LoRA.
5. Разобранный пример: параметры и mask.
6. Самопроверка с ответами.

**Разобранный пример:** Для $W$ размера $1024\times1024$ имеется 1048576 weights. Rank 8 даёт $8\cdot1024+1024\cdot8=16384$ adapter weights, 1.5625% исходного числа. Если $\alpha=8$, coefficient $\alpha/r=1$; при $\alpha=16$ он равен 2, contribution меняется даже при прежних $A,B$.

В scalar mask example known pixel 0.7, generated pixel 0.2, mask $m=0$ дают final $(1-m)0.7+m0.2=0.7$. При $m=1$ результат 0.2. Перепутанная convention mask меняет область редактирования на противоположную; shape masks при этом остаётся корректной.


**Схемы и разбор:** ControlNet: Noisy latent + text condition → Locked model + trainable copy → Spatial control → zero convs → Residual injection → denoising; LoRA / editing: Base weights W, frozen → Train A,B → low-rank ΔW → Image + noise / edit mask → Conditional sampling → edited image.

## Оценка генерации: fidelity, diversity, условия и FID

**Статус сценария:** authored — расширение CV; приёмка текста отдельно

**Учебный вопрос:** Как проверить качество генератора без одного вводящего в заблуждение числа?

**Уровень:** основа ветки. **Предпосылки:** cv-generative, cv-latent-diffusion

**Потребители:** Самостоятельное применение.

**Порядок объяснения:**

1. Несколько независимых свойств.
2. FID и feature distributions.
3. Оценка условия и человеческое сравнение.
4. Разобранный пример: FID в одном dimension.
5. Диагностика и стоимость.
6. Самопроверка с ответами.

**Разобранный пример:** Real features имеют mean 0 и variance 1, generated — mean 1 и variance 4. В 1D formula упрощается до $(0-1)^2+1+4-2\sqrt{1\cdot4}=1+5-4=2$. Если mean и variance совпадут, FID станет 0 даже для распределений с разными высшими moments. Значит, «FID=0» не доказывает побитовое совпадение datasets.

В парном сравнении 100 независимых prompts model A выигрывает 60 раз, B — 40, без ties. Оценка preference rate 0.6; standard error Bernoulli approximation $\sqrt{0.6\cdot0.4/100}\approx0.04899$. Приближённый 95% interval 0.504..0.696. Малый перевес требует учитывать uncertainty; эта approximation не заменяет подходящий interval для малых samples и зависимых ratings.


**Схемы и разбор:** Feature metric: Real images / generated images → Одинаковый feature extractor → Mean + covariance estimates → FID + protocol / sample count; Conditional evaluation: Фиксированные prompts / controls → Seeds + sampler + budget → Task checks + blind preference → Slices + uncertainty + failures.
