# Сборка и проверка курса

Учебный текст редактируется в Markdown пяти модулей. `course.json` задаёт порядок, зависимости, уровни, маршруты и перенаправления старых HTML-закладок. Для сборки используется Node.js 20+; необходимые версии marked и KaTeX включены в `vendor/` вместе с лицензиями.

Из корня проекта:

```text
node tools/build_course.cjs
node tools/build_course.cjs --check
python -X utf8 tools/audit_course.py
node tools/check_reader.cjs
```

Первая команда генерирует оглавления, планы/сценарии и HTML. Вторая сравнивает их с результатом повторной сборки без записи. Python-аудит проверяет snapshot, отдельные source/target блоки и неизменность формул, dependency graph, независимые маршруты, ссылки, SVG и новые числовые примеры.

Браузерная проверка требует Playwright и Chromium либо установленный Edge. Путь к каталогу пакетов можно задать в `COURSE_NODE_MODULES`. В Codex используется bundled runtime. Проверка блокирует внешний HTTP, сохраняет результаты в `editorial/browser-audit.json`, снимки — в `editorial/qa/`. В ограниченном Windows sandbox Edge может не создать временный профиль; это ограничение запуска браузера, отдельное от сборки HTML.

Скрипты одноразовой перестройки перенесены в [`archive/rebuild-tooling/`](../archive/rebuild-tooling/README.md). Они не используются для обычной сборки и не являются текущим источником учебного текста. После приёмки миграция блокируется файлом `editorial/migration-complete.json`.

Карта source/target хранит контрольные суммы отдельных перенесённых блоков. Если содержательно редактируется такой блок, нужно пересмотреть его запись и обоснование действия в `editorial/coverage.json`; автоматическая перезапись всех hashes без проверки смысла не заменяет редакционную приёмку. Добавления можно писать обычным Markdown; при изменении структуры обновляется `course.json`.
